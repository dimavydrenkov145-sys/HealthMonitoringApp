# Руководство пользователя

## 1. Установка
Никакой установки не требуется. Скопируйте папку `HealthMonitoringApp` на компьютер и запустите `HealthMonitoringApp.exe`.

## 2. Начало работы
После запуска откроется главное окно.

### 2.1. Ввод данных
Заполните поля:
- **Шаги** — целое число (например, 8000).
- **Калории** — целое число (например, 500).
- **Пульс** — ударов в минуту (например, 75).
- **Давление** — два числа: верхнее и нижнее (например, 120 и 80).
- **Уровень сахара** — число с точкой (например, 5.5).

### 2.2. Сохранение
Нажмите кнопку **«Сохранить показатель»**. Если все данные введены верно, запись добавится в таблицу истории, а в жёлтой области появится рекомендация.

### 2.3. Просмотр истории
Нижняя таблица показывает последние 20 записей. Новые записи появляются сверху.

### 2.4. Ошибки
Если поле содержит буквы или пустое, программа покажет сообщение об ошибке. Исправьте ввод и повторите сохранение.
