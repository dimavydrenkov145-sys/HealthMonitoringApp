# Требования к программному продукту «Сервис мониторинга здоровья»

## 1. Введение
Продукт предназначен для ведения личного дневника здоровья с возможностью ввода показателей, хранения истории и получения автоматических рекомендаций.

## 2. Функциональные требования
| ID | Требование |
|----|-------------|
| FR1 | Пользователь должен иметь возможность вводить: шаги (целое число), калории (целое), пульс (целое), давление (систолическое и диастолическое), уровень сахара (число с плавающей точкой). |
| FR2 | Система должна сохранять введённые данные в локальную базу данных SQLite с меткой времени. |
| FR3 | Система должна отображать последние 20 записей в виде таблицы. |
| FR4 | После сохранения система должна анализировать показатели и выдавать текстовую рекомендацию. |
| FR5 | При некорректном вводе (буквы, пустые поля) система должна показывать сообщение об ошибке. |

## 3. Нефункциональные требования
| ID | Требование |
|----|-------------|
| NFR1 | Платформа: Windows 10/11. |
| NFR2 | Среда выполнения: .NET Framework 4.7.2 или выше. |
| NFR3 | Время отклика на сохранение не более 1 секунды. |
| NFR4 | База данных — локальный файл `health.db`, не требующий установки сервера. |ss
