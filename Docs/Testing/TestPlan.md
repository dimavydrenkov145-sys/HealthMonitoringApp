# План тестирования «Сервис мониторинга здоровья»

## 1. Объект тестирования
Приложение HealthMonitoringApp.exe (Windows Forms).

## 2. Виды тестирования
- Функциональное (проверка соответствия требованиям).
- Нагрузочное (не требуется, т.к. один пользователь).
- Тестирование интерфейса.

## 3. Тестовые случаи

| TC_ID | Описание | Входные данные | Ожидаемый результат |
|-------|----------|----------------|----------------------|
| TC-01 | Ввод корректных данных | Шаги=8000, Калории=500, Пульс=75, Давление=120/80, Сахар=5.5 | Запись появляется в таблице, выводится рекомендация «Все в норме» |
| TC-02 | Ввод некорректных символов | Шаги=«abc» | Сообщение об ошибке «Входная строка имела неверный формат» |
| TC-03 | Пустые поля | Ничего не введено, нажать «Сохранить» | Сообщение об ошибке с просьбой заполнить все поля |
| TC-04 | Высокое давление | Систолическое=150 | Рекомендация содержит «Повышенное давление» |
| TC-05 | Низкий пульс | Пульс=55 | Рекомендация содержит «Замедленный пульс» |
| TC-06 | Повышенный сахар | Сахар=7.2 | Рекомендация содержит «Повышенный сахар» |

## 4. Инструменты тестирования
- Ручное тестирование.
- Визуальный контроль.
