# Журнал изменений

## [1.0.0] - 2025-05-15
### Добавлено
- Первая версия приложения.
- Возможность ввода шагов, калорий, пульса, давления, сахара.
- Локальное хранение в SQLite (таблица HealthRecords).
- Отображение истории последних 20 записей.
- Формирование рекомендации на основе анализа показателей.
- Обработка ошибок ввода (пустые поля, буквы).
- Поддержка десятичной точки для сахара (InvariantCulture).

### Технические детали
- Проект создан в Visual Studio 2022.
- Windows Forms, .NET Framework 4.7.2.
- Пакет NuGet: System.Data.SQLite.Core.
- Git-репозиторий с .gitignore.

### Известные проблемы
- При вводе сахара с запятой (5,5) требуется использовать точку. (Можно исправить в следующих версиях).
