# Технический проект «Сервис мониторинга здоровья»

## 1. Архитектура приложения
- **Тип**: локальное десктопное приложение.
- **Архитектурный стиль**: модель-представление-контроллер (упрощённый).
  - **Модель**: класс HealthRecords (сущность БД) + SQLite.
  - **Представление**: Windows Forms (Form1).
  - **Контроллер**: код в Form1 (btnSave_Click, LoadHistory и т.д.).

## 2. Технологический стек
| Компонент | Технология |
|-----------|-------------|
| Язык программирования | C# |
| Платформа | .NET Framework 4.7.2 |
| Графический интерфейс | Windows Forms |
| База данных | SQLite (System.Data.SQLite.Core) |
| Система контроля версий | Git |

## 3. Структура базы данных
Таблица `HealthRecords`:
- `Id` INTEGER PRIMARY KEY AUTOINCREMENT
- `Date` TEXT (yyyy-MM-dd HH:mm)
- `Steps` INTEGER
- `Calories` INTEGER
- `Pulse` INTEGER
- `Systolic` INTEGER
- `Diastolic` INTEGER
- `BloodSugar` REAL

## 4. Алгоритм формирования рекомендации
1. Систолическое давление > 140 → предупреждение о гипертонии.
2. Систолическое давление < 100 → предупреждение о гипотонии.
3. Пульс > 100 → тахикардия.
4. Пульс < 60 → брадикардия.
5. Сахар > 6.1 → гипергликемия.
6. Если ни одно условие не сработало — «Все показатели в норме».

## 5. Обработка ошибок
При парсинге чисел используется `int.Parse` и `double.Parse` с обработкой исключений. При пустых полях выводится сообщение.
